# Financial Dashboard

A Flask-based interactive financial dashboard that provides historical analysis and Monte Carlo forecasting for McDonald's and Starbucks financial metrics.

## Features

- **Multi-Dataset Support**: Analyze financial data for McDonald's and Starbucks
- **Historical Data Visualization**: Interactive charts showing historical financial metrics
- **Monte Carlo Forecasting**: Scenario-based probabilistic forecasting (bull, base, bear cases)
- **Company Comparison**: Compare metrics side-by-side between companies
- **Multiple Metrics**: 
  - McDonald's: Market cap, Revenue, Earnings, EPS, Operating Margin, Total assets, Debt, P/E ratio, Cash on Hand, Dividend Yield
  - Starbucks: Revenue, COGS, Gross Profit, SG&A, R&D, Marketing, EBITDA, Depreciation, EBIT, Interest, EBT, Tax, Net Income, Working Capital, CapEx

## Technology Stack

- **Backend**: Flask 3.1.3
- **Data Processing**: 
  - pandas 3.0.3
  - numpy 2.4.6
  - scikit-learn 1.8.0 (for machine learning and predictions)
- **Database**: Excel/CSV data files
- **Frontend**: JavaScript with Chart.js for interactive visualizations
- **Server**: Gunicorn 23.0.0

## API Endpoints

- **GET `/`** - Main dashboard page
- **GET `/api/historical`** - Retrieve historical data for a specific metric
  - Parameters: `dataset` (mcd/sbux), `metric`
- **GET `/api/predict`** - Get Monte Carlo predictions
  - Parameters: `dataset`, `metric`, `n_future`, `n_simulations`, `noise_pct`
- **GET `/api/overview`** - Get key metrics cards with year-over-year changes
  - Parameters: `dataset`
- **GET `/api/comparison`** - Compare metrics between two companies
  - Parameters: `dataset_a`, `dataset_b`, `metric`

## Configuration

Key simulation parameters (in `app.py`):

- **TAX_RATE**: 0.25 (25% tax rate for earnings adjustments)
- **BASE_GROWTH**: 0.02 (2% base annual growth)
- **SCENARIO_WEIGHTS**: Distribution of forecast scenarios
  - Bull: 20% (aggressive growth)
  - Base: 60% (moderate growth)
  - Bear: 20% (negative growth)

## How Monte Carlo Forecasting Works

The application uses Monte Carlo simulations with three scenarios:

1. **Bull Case**: +4% additional annual growth, lower noise (0.6x), -3% tax adjustment
2. **Base Case**: Baseline growth, standard noise (1.0x), no tax adjustment
3. **Bear Case**: -5% annual growth, higher noise (1.5x), +3% tax adjustment

For each simulation:
- Historical data is bootstrapped with scenario-specific noise
- A polynomial regression model (degree 2) is trained
- Predictions are adjusted for compound growth and tax effects
- 1,000 simulation paths are generated by default (configurable up to 10,000)

Results include percentile distributions (5th, 25th, median, 75th, 95th) and model accuracy metrics (MAE, R²).

## Data Files

- **McDonalds_Financial_Statements.csv**: Historical financial data for McDonald's
- **financial_data_sbux.xlsx**: Historical financial data for Starbucks (loaded and normalized to billions)

## Notes

- All financial figures are normalized to billions (USD)
- Earnings-type metrics receive tax-rate adjustments in forecast scenarios
- The application supports comparing metrics across companies for overlapping years
- Forecasts extend up to 15 years in the future
